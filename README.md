# Student Attendance Monitor

Real login + database via Supabase. Pages: landing (index.html) with Teacher/Student login,
Teacher Dashboard (dashboard.html, served at /teacher), Students, Attendance,
Student own-attendance view (student.html, served at /student).

Setup: see supabase/README.md — run supabase/schema.sql in Supabase SQL Editor,
turn off email confirmations, then fill config.js with the Project URL + anon key.
Deployed via GitHub + Vercel.
